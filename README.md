🇪🇸 Spanish Club Learning Hub (Centro de Aprendizaje)

Welcome to the Spanish Club Learning Hub repository! This is a single-page, fully interactive web application designed for Spanish clubs, language learners, and study groups to practice, chat, listen to music, play grammar games, and share multimedia learning resources together.

✨ Features

💬 Community Chat & Practice Forum:

Practice real Spanish conversations in an encouraging environment.

Filter messages by proficiency level (Principiante, Intermedio, Avanzado).

Daily discussion prompts with quick-reply templates.

Persists messages locally in the browser.

🎮 Interactive Arcade Games Center:

Verb Conjugator Master: Practice verb conjugations across levels (A1 to C1) and tenses (Present, Preterite, Imperfect, Future) with an integrated accent keyboard (á, é, í, ó, ú, ñ).

Vocab Association Matcher: Matching cards game for vocabulary retention.

Sentence Builder (La Frase): Reorder scrambled word blocks to construct grammatically correct sentences.

Listening Comprehension (Comprensión Auditiva): Powered by the native Web Speech API for real-time audio pronunciation practice.

🎵 Music & Radio Hub:

Embedded audio player for Spanish songs across genres (Salsa, Flamenco, Reggaeton, Indie, Bachata).

Togglable lyrics and key vocabulary breakdowns.

Community recommendation modal so members can submit their favorite tracks.

📚 Media & Resource Library:

Curated library for Spanish podcasts, movies, YouTube channels, and books.

Filterable by media type and difficulty.

Custom submission modal to allow members to add new learning resources.

🌐 Dual-Language Support (ES / EN):

Instant toggle between Spanish and English for all UI elements, controls, and resource summaries.

🛠️ Built With

HTML5 & Vanilla JavaScript: Lightweight, fast, and dependency-free logic.

Tailwind CSS (via CDN): Modern, responsive styling with dark mode aesthetics.

Font Awesome Icons: Visual icons for intuitive navigation.

Web Speech API: Browser-native text-to-speech engine for audio comprehension games.

HTML5 LocalStorage: Persistent storage for user chat messages, submitted tracks, and added resources without needing a backend server database.

🚀 How to Host on GitHub Pages (100% Free)

You can publish this website live on the web in less than 2 minutes using GitHub Pages:

Step 1: Create a Repository

Log in to your GitHub Account.

Click New Repository (or the + icon in the top right).

Name your repository (e.g., spanish-club-hub).

Keep it Public.

Click Create repository.

Step 2: Upload Files

Click Uploading an existing file in the setup section.

Drag and drop your index.html and README.md files into the upload box.

Scroll down and click Commit changes.

Step 3: Enable GitHub Pages

Go to your repository's Settings tab (gear icon at the top).

On the left sidebar, click Pages (under the "Code and automation" section).

Under Build and deployment > Source, select Deploy from a branch.

Set the branch to main (or master) and folder to / (root).

Click Save.

🎉 You're done! In about 1 to 2 minutes, GitHub will generate a live link (e.g., https://yourusername.github.io/spanish-club-hub/) that you can share with all your Spanish club members!

💻 Running Locally

To run this project locally on your machine:

Clone or download this repository.

Open index.html directly in any web browser (Chrome, Firefox, Safari, Edge).

No server setup or npm install required!
